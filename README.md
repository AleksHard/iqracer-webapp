# IQRacer — Сканер QR

Мини-приложение (Telegram Web App) для сканирования QR-кодов на чекпоинтах игры **IQ Racer**.

## Что делает

Открывает камеру через встроенный сканер Telegram и по нажатию кнопки считывает QR-код с чекпоинта. Считанный код сразу отправляется боту (`tg.sendData`), после чего окно приложения закрывается.

## Как это работает

- Страница подключает [Telegram Web App JS SDK](https://core.telegram.org/bots/webapps) (`telegram-web-app.js`).
- По клику на кнопку «Сканировать QR-код» вызывается `tg.showScanQrPopup(...)`.
- При успешном считывании код отправляется боту через `tg.sendData(text)`, и приложение закрывается (`tg.close()`).
- Цвета интерфейса берутся из темы Telegram (`--tg-theme-*`), чтобы страница выглядела нативно в любой теме клиента.

## Запуск и тестирование

Приложение рассчитано на запуск **внутри Telegram**, как кнопка веб-приложения, привязанная к боту:

1. Разместите `index.html` на HTTPS-хостинге (GitHub Pages, Vercel и т.п.).
2. Укажите URL приложения в настройках Web App у бота через [@BotFather](https://t.me/BotFather).
3. Откройте бота в Telegram и запустите Web App — сканер должен появиться сразу.

Если открыть `index.html` напрямую в обычном браузере (не через Telegram), сканер будет недоступен — приложение покажет подсказку с просьбой открыть страницу через бота.

## Стек

Чистый HTML/CSS/JS, без сборки и зависимостей — единственный внешний скрипт это Telegram Web App SDK.

## Мини-игра: пазл (`puzzle.html`)

Отдельная страница-пазл: картинка разбита на плитки (по умолчанию 9, 3×3), плитки перемешаны —
нужно собрать картинку, меняя плитки местами. Работает и в Telegram, и в обычном браузере
(тема Telegram подхватывается сама), зависимостей нет.

- Адрес после публикации: `https://alekshard.github.io/iqracer-webapp/puzzle.html`
- Управление: нажать на плитку — она подсветится; нажать на другую — они поменяются местами.
  Повторное нажатие на подсвеченную плитку снимает выбор. Кнопки: «Подсмотреть» (держать),
  «Номера», «Заново», размеры 3×3 / 4×4 / 5×5.
- Картинка по умолчанию — файл `puzzle.jpg` рядом со страницей (заменить фото = заменить этот файл).
  Если файла нет, берётся нарисованная в коде запасная картинка.
- Считаются ходы (один обмен = один ход) и время, лучший результат для каждого размера хранится на
  устройстве игрока. Любая раскладка решаема: меняться местами можно любые две плитки.

Параметры в адресе:

| Параметр | Что делает |
|---|---|
| `?img=puzzle-images/p1-1a2b3c4d.jpg` | другая картинка (так бот открывает загруженные картинки): файл рядом со страницей или полная ссылка; любое соотношение сторон (обрезается по центру до квадрата). Если не загрузилась — берётся `puzzle.jpg` |
| `?size=3` / `4` / `5` | размер поля (по умолчанию 3, последний выбор запоминается) |
| `?report=1` | после победы появляется кнопка «Отправить результат боту» (только если страницу открыли кнопкой клавиатуры бота) |
| `?auto=1` | вместе с `report=1`: результат уходит боту сам через пару секунд после победы, приложение закрывается |

Каталог `puzzle-images/` ведёт бот IQRacer: туда он коммитит картинки, которые организатор загружает
в Telegram (файлы вида `p1-1a2b3c4d.jpg`), и сам удаляет заменённые. Вручную их менять не нужно.

Формат отправки боту: `PUZZLE_SOLVED|размер|ходы|секунды`, например `PUZZLE_SOLVED|3|7|41`.
Бот IQRacer разбирает такие сообщения: игрокам пазл показывается только как дополнительное задание
после точки, помеченной в таблице с загадками (см. README бота). Ссылки на страницу в игре нет —
игроки попадают на неё только через кнопку, которую выдаёт бот.
